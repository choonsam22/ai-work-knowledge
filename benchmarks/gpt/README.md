# benchmarks/gpt

ChatGPT가 조사한 AI 생산성 벤치마킹 자료 전용 폴더입니다.

## 작업 원칙

- 기존 `benchmarks/2026-08-07_ai-productivity-benchmarking.md`의 40개사 Long List와 **중복되지 않는 신규 기업/사례를 우선 조사**합니다.
- 새 조사 전에는 반드시 아래 자료를 먼저 확인합니다.
  1. `benchmarks/2026-08-07_ai-productivity-benchmarking.md`
  2. `benchmarks/claude/` 전체
  3. `benchmarks/gpt/` 기존 조사파일
- Claude가 이미 조사한 기업/사례는 원칙적으로 중복 조사하지 않습니다. 다만 사실 검증, 최신 업데이트, 다른 관리부문 Use Case 추가가 목적이면 보완 조사할 수 있습니다.
- 조사 결과는 회사 단위보다 **Use Case 단위**로 쪼개어 기록합니다.
- 세아제강 제조현장 자체보다 **관리부문/사무직 생산성**에 직접 연결되는 사례를 우선합니다.
- 챗봇/Agent라는 기술명보다 기존 업무의 어떤 비부가가치 단계가 제거·축소됐는지를 중심으로 기록합니다.

## 권장 기록 항목

- 기업 / 산업
- 관리부문(영업·구매·재무·HR·기획·법무 등)
- 기존 업무 / 문제
- AI 적용 방식
- Before → After
- 정량효과
- AI Level (L1 Assist ~ L5 AI-native, Working Mapping)
- 출처 및 신뢰도
- 세아제강 관련성

## AI 간 분업

- `benchmarks/claude/`: Claude 조사 결과
- `benchmarks/gpt/`: ChatGPT 조사 결과
- 루트 Benchmark 문서: 공통 기준선 / 초기 40개사 Long List

향후 통합 시에는 두 AI 폴더의 결과를 함께 확인해 중복을 제거하고, 관리부문별·AI Level별 Benchmark Map으로 합칩니다.
