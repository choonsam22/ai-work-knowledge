# 🛍️ [타당성 검증] TotalEnergies 구매 에이전트의 사용자 이탈 허들과 무이탈 UI 설계 방안

> **분석 및 검증자:** Gemini (Antigravity) 에이전트  
> **검증 대상 문서:** `TotalEnergies - Microsoft Copilot Studio BuyerCompanion Case Study`  
> **목적:** €50,000 이하 소액 구매의 업무 처리를 AI가 다 알아서 대행해 준다는 마케팅 자료의 이면을 분석하고, 현업 임직원들이 이탈 없이 사용하게 만드는 현실적 UI/UX를 도출합니다.

---

## 1. 피상적 홍보와 숨겨진 현실 (Marketing vs. Reality)

### 📢 솔루션사 홍보 자료 (Microsoft Presentation)
> *"TotalEnergies는 구매 에이전트 'BuyerCompanion'을 배포하여 글로벌 15,000명 임직원의 소액 조달 업무 시 규격을 자동 구조화하고 기존 마스터 단가 계약을 100% 자율 체크함으로써, 구매 리드타임을 대폭 축소하고 조달 비용의 10%를 절감했습니다."*

### 🔍 Gemini의 냉정한 현실 검증 (Reality Check)
1. **임직원의 챗봇 UI 혐오와 극도의 귀찮음:**
   * 소액 구매(MRO, 사무 비품, 소모성 공구 등)가 발생하는 실제 현업 임직원들은 구매 업무 자체가 본업이 아닙니다. 이들의 유일한 목표는 '가장 최소한의 클릭으로 1분 안에 구매 신청을 끝내는 것'입니다.
   * AI 비서와 채팅창을 열어 *"안녕하세요, 무엇을 구매하시겠습니까?"*라는 질문에 장황하게 품목 스펙을 직접 타이핑하여 작성하는 과정 자체가 임직원들에게는 치명적인 시간 낭비이자 귀찮음으로 다가옵니다. 결국 임직원은 챗봇을 끄고 예전처럼 구매 담당자에게 다짜고짜 메일을 보내거나 전화를 해버립니다.
2. **마스터 계약 데이터(Master Contract DB) 유실 시의 대형 대조 참사:**
   * AI가 기존 프레임워크 계약(단가 계약 등)에 수천만 원의 단가 할인이 이미 맺어진 업체를 자동으로 찾아내 매칭해 주기 위해서는, 내부 계약 데이터베이스가 실시간으로 완벽하게 연동 및 정제(Indexing)되어 있어야 합니다.
   * 현실적으로 기업의 구매 계약 조항과 예외 조항들은 PDF나 복잡한 엑셀 형태로 사일로화되어 유실되어 있는 경우가 많습니다. 데이터가 누락되어 있다면 AI 에이전트는 계약 단가가 없는 엉뚱한 비정형 제품이나 고가 단가의 업체를 추천하는 '오인 추천 리스크'를 필연적으로 유발합니다.

## 2. 세아제강 도입 시 발생할 치명적 장벽 (Structural Obstacles)

만약 이 에이전트 모델을 세아제강 영업 및 구매 조달 파트에 이식하려 한다면 다음 현실적 제약에 부딪힙니다.

### ① 자재 및 외주 서비스 스펙의 불명확성
* 세아제강의 공장 유지보수나 정기 보수를 위한 외주 용역, 정밀 기계 부품은 일반적인 MRO 자재처럼 기성품 스펙으로 매핑되지 않습니다. 현업 실무자 스스로도 스펙을 명확히 정의하지 못하는 특수 품목이나 맞춤 외주 용역의 경우, AI는 스펙을 자동으로 구조화해 줄 수 없으며 엉뚱한 가이드라인만 제시하여 행정 혼선이 발생합니다.

### ② "Non-intrusive(비침습적)" 환경의 부재
* 챗봇을 별도 포털이나 외부 모바일 앱으로 떼어내어 접속하게 유도하면 로그인 번거로움과 접속 귀찮음으로 인해 임직원의 사용률이 5% 미만으로 수렴하게 됩니다.

## 3. 세아제강을 위한 '진짜' 현실적 구매 효율화 대안 (UI/UX Shift)

우리는 사용률이 제로에 수렴할 '대화형 챗봇'을 설계하지 말고, 임직원이 눈치채지 못하는 사이에 시스템 내부에서 조용히 작동하는 **"백그라운드 비침습적 임베디드 매칭(Non-intrusive Embedded Matching)"** 방식을 권장합니다.

```text
[임직원의 일반 ERP 구매 품의 작성 단계]
- 텍스트 입력 칸에 "공장 청소용 브러시 50개 필요" 기입 후 엔터
                         │
                         ▼
┌────────────────────────────────────────────────────────┐
│     백그라운드 AI 에이전트 RAG 데이터 매칭 작동        │
└────────────────────────────────────────────────────────┘
                         │
                         ▼
┌────────────────────────────────────────────────────────┐
│     ERP 품의 화면 우측에 '조용한 팝업 알림 위젯' 표시  │
│                                                        │
│   "잠시만요! 세아제강은 '한국브러시' 업체와 이미       │
│   개당 5,000원에 연간 단가 계약(No.261)이 맺어져 있습니다.│
│   현재 기입하신 단가(7,500원) 대비 25만원 절감 가능합니다." │
│   👉 [이 단가 계약으로 원클릭 적용 및 자동 매핑 완료]     │
└────────────────────────────────────────────────────────┘
```

1. **'임베디드 위젯(Embedded Widget)화' 적용 (Step 1):**
   * 현업이 별도 챗봇 앱을 켤 필요가 없어야 합니다. 세아제강 임직원이 평소 사용하는 내부 ERP나 구매 포털의 결재/품의 작성 페이지 우측에 작은 위젯 팝업 형태로 AI가 조용히 개입해야 합니다.
2. **'RAG 기술 기반 스마트 사양 전처리' (Step 2):**
   * 현업이 자연어로 대략 입력한 품목 정보를 에이전트가 뒤에서 가볍게 읽고, 사내 자재 마스터 데이터(Material Master DB) 및 표준 단가 계약서에 등재된 실제 품목과 벡터 유사도를 비교하여 최적의 부품과 공급사를 자동으로 우측 화면에 정렬해 제시해 줍니다.
3. **'결재선 사전 승인 가이드라인' 연계:**
   * 구매 최종 결재를 올리기 전, AI가 "표준 단가 계약이 있음에도 불구하고 왜 다른 업체의 고가 제품을 구매하려 하는가?"에 대한 사유 입력을 의무화하여 비정형 소액 무단 구매 행위(Maverick Spend)를 자연스럽게 시스템적으로 통제하고 이탈을 원천 차단합니다.
